## 1. الغرض

تحمي سياسة الاستخدام المقبول هذه Supplify والمطاعم والموردين والضيوف والسائقين والموظفين والمديرين والمنصة من النشاط غير القانوني أو المسيء أو الاحتيالي أو غير الآمن أو الضار.

## 2. السلوك المحظور

يجب عدم:

1. مخالفة القانون.
2. ارتكاب الاحتيال.
3. إنشاء أعمال وهمية أو مستخدمين وهميين أو طلبات وهمية أو مراجعات وهمية أو عروض وهمية.
4. رفع برامج ضارة أو ملفات ضارة.
5. محاولة الوصول غير المخوّل.
6. التدخل في أمان المنصة أو بنيتها التحتية.
7. استخراج البيانات أو الهندسة العكسية أو نسخ المنصة بشكل غير قانوني.
8. تجاوز الأدوار أو الفوترة أو الحدود أو عزل المستأجرين أو بوابات الميزات.
9. إرسال بريد مزعج للمستخدمين أو الضيوف أو المطاعم أو الموردين أو السائقين.
10. مضايقة أو تهديد أو تمييز أو إساءة معاملة الآخرين.
11. رفع محتوى ليس لديكم الحق في استخدامه.
12. تضليل المستخدمين بشأن الأسعار أو الخصومات أو المنتجات أو المخزون أو التوصيل أو الهوية.
13. التلاعب بالمقاييس أو أداء التعزيز أو الظهور أو التحليلات.
14. مشاركة حسابات تسجيل الدخول بشكل غير سليم.
15. استخدام Supplify لنقل محتوى غير قانوني أو ضار.

## 3. المنتجات والمحتوى المحظور

يجب على الموردين عدم إدراج أو الترويج لمنتجات غير قانونية أو مقلّدة أو مسروقة أو غير آمنة أو منتهية الصلاحية أو ذات تصنيف خاطئ أو غير مخوّلة أو احتيالية أو ضارة أو محظورة من قبل Supplify.

قد تتطلب المنتجات الخاضعة لتنظيم خاص إثبات تفويض أو ترخيص أو امتثال.

## 4. العروض والتعزيزات المضلّلة

يجب على الموردين عدم إنشاء خصومات وهمية أو إلحاح وهمي أو أسعار مضلّلة أو عروض غير متوفرة أو مخزون كاذب أو ادعاءات أداء كاذبة. يجوز لـ Supplify إزالة أو رفض أي عرض أو تعزيز مضلّل.

## 5. إساءة استخدام المراسلة

يجب على المستخدمين عدم إساءة استخدام الدردشة أو البريد الإلكتروني أو واتساب أو الرسائل القصيرة أو الإشعارات الفورية أو التذكيرات أو اتصالات الحجز العام. يجب أن تلتزم الرسائل التسويقية بالقوانين المعمول بها ومتطلبات الموافقة.

## 6. إساءة الاستخدام الأمني

يجب عدم اختبار أو مسح أو مهاجمة أو إرهاق أو استغلال أنظمة Supplify دون تفويض كتابي.

## 7. الإنفاذ

يجوز لـ Supplify إزالة المحتوى أو تقييد الميزات أو تعليق الحسابات أو حظر المستخدمين أو إلغاء التعزيزات أو إلغاء العروض أو تعطيل الإشعارات أو قفل المستأجرين أو إنهاء الحسابات أو الإبلاغ عن السلوك للسلطات.
