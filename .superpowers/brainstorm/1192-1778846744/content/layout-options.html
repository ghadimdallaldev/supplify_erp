How should the content area be organized?

Same widgets, three different arrangements. The sidebar stays dark navy in all three.

Supplier Dashboard

A — Classic ERP (KPIs → 2-column)

Full-width KPI strip across the top, then a wide main column (chart + orders + calendar) with a narrow sidebar (status + role widget). Familiar, structured, easy to scan top-to-bottom.

Supplier Dashboard

B — Bento Grid

Modular tiles of varying sizes in a 4-column grid. KPIs top row, charts + orders + status middle row, calendar + role widget bottom. No single dominant column — feels modern and spatial.

C — Sectioned with Dark Metrics Header

A dark-on-dark KPI header band pinned at the top (echoes the navy sidebar), then clearly labeled sections below: Activity, Analytics, Calendar. Structured vertical flow, easy to navigate.
