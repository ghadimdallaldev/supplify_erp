# Product

## Register

product

## Users

Restaurant operators, suppliers/distributors, their staff, drivers, and platform
admins. They work inside Supplify all day to run a food-supply B2B operation:
placing and fulfilling orders, managing inventory and deliveries, handling
billing/subscriptions, reservations, staff, and disputes. Context is task-heavy
and repeated — speed, density, and trustworthiness matter more than novelty.

## Product Purpose

Supplify is a multi-tenant ERP + B2B marketplace for the restaurant supply chain
(orders, fulfillment/delivery, inventory, billing, suppliers, staff, reservations,
admin). Success is operators trusting it for daily work: every screen legible at a
glance, consistent, and fast.

## Brand Personality

Confident, crisp, modern. Three words: **precise, calm, premium.** It should feel
like a best-in-class product tool (Linear, Stripe, Vercel) — not enterprise
software. Voice is direct and plain; the UI disappears into the task.

## Anti-references

- Generic enterprise ERP dashboards (SAP/NetSuite/Odoo): dense gray chrome, tiny
  fonts, inconsistent page widths, weak hierarchy, everything the same visual weight.
- "Bootstrap admin template" look: stock cards everywhere, timid typography.
- Over-decoration: gradient text, glassmorphism, decorative motion, loud color on
  inactive states.

## Design Principles

1. **One width, everywhere.** Page content sits in a single shared container so the
   layout never jumps between screens.
2. **Confident hierarchy.** Page titles and top-of-page summaries read large and
   clear; secondary text stays legible (WCAG AA), never decorative gray.
3. **Earned familiarity.** Standard SaaS patterns (top bar + side nav, tables,
   tabs), consistent component vocabulary screen to screen.
4. **Restrained color.** Calm neutrals; the violet brand accent is reserved for
   primary actions, current selection, and state — not decoration.
5. **Motion conveys state, not flair.** 150–250ms, reduced-motion honored.

## Accessibility & Inclusion

WCAG 2.1 AA: body text ≥4.5:1, large text ≥3:1. Honor `prefers-reduced-motion`
(already wired). Keyboard focus states on all interactive elements.
